Fake News Detection Using Python

📌 Project Overview

Fake News Detection is a Python-based project designed to identify whether a given news article is Real or Fake.

The project uses a dataset containing news information and applies Python programming techniques to analyze and classify news content.

🎯 Objectives

- To identify fake and misleading news.
- To analyze news data using Python.
- To classify news as Real or Fake.
- To understand the application of data analysis in detecting misinformation.

🛠️ Technologies Used

- Python
- Pandas
- Excel Dataset

📂 Project Structure

fake_news_detection/
│
├── fake_news_detection.py
├── fake_news_dataset.xlsx
└── README.md

⚙️ How It Works

1. Load the news dataset.
2. Read and process the available data.
3. Analyze the news information.
4. Apply the detection logic.
5. Display the classification result.

🚀 How to Run the Project

Step 1: Clone the repository.

git clone https://github.com/akilasakthivel42/fake_news_detection.git

Step 2: Navigate to the project folder.

cd fake_news_detection

Step 3: Install the required library.

pip install pandas openpyxl

Step 4: Run the Python program.

python fake_news_detection.py
